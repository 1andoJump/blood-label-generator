# 血样标签生成器

把只含姓名的原始清单，按规则展开成标签表格（txt / xls），供 Dlabel云标签 软件打印血样标签使用。

## 使用

打开页面，把原始清单粘贴进输入框，实时预览后下载 txt 或 xls 文件。

### 输入格式

每行一条：`前缀：姓名 姓名…`（冒号可省略，姓名用逗号或空格分隔）

- 行首是数字 = 病房血（数字忽略）
- 行首含「穿刺」= 穿刺血

### 展开规则

| 输入行 | 展开结果 |
| --- | --- |
| `数字：姓名（2紫）` | 5×PBMC + 4×plasma |
| `数字：姓名（2紫2花）` | 5×PBMC + 5×PBMC（花）+ 4×plasma + 6×plasma（花） |
| `穿刺：姓名（3紫）` | 5×PBMC |
| `穿刺：姓名（5紫）` | 10×PBMC |

- 「2紫2花」也写作「紫2花2」「2花2紫」等
- 穿刺血未标注时默认按 3紫（5紫 需注明）
- 输出顺序：穿刺血 → 花头管（花）→ 普通病房血（紫），同类内按输入顺序

### 输出

- **txt**：`组数,姓名,标签`（PC 版 Dlabel；文件名用日期命名，PC 版以文件名作为标签日期）
- **xls**：`姓名,类型`（iOS 版 Dlabel；不含日期列）

## 说明

- 纯前端，姓名数据不离开本地，无后端依赖
- 单文件 `index.html`，已内联 SheetJS 库，可离线使用
